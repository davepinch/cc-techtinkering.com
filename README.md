# cc-techtinkering.com

This repository contains information about selected pages on the TechTinkering blog (https://techtinkering.com). TechTinkering is a great blog by Lawrence Woodman with posts on CP/M, the VIC-20, BASIC, and numerous other vintage technologies.  I (David Pinch) have no association, relationship, or contact with TechTinkering except as a reader.

## What is the purpose of this repository?

I maintain a curated list of interesting web pages at https://pinchy.cc. For significant websites that I link to, I manage those links in a GitHub repository such as this one. For each page, I have a corresponding text file with YAML properties describing the page. I do not import full content, instead encouraging visitors to visit the real website to actually read the content. The information I track is used to organize the links on my own website. For example, I use scripts to cross-reference related pages. I also have a script that periodically archives linked pages in the Internet Archive.

## Is this legal from a copyright/licensing perspective?

Yes. I do not import full content from techtinkering.com even though the author, Lawrence Woodman, licenses his content under a permissive Creative Commons license. I do import small excerpts to serve as a preview, and I occasionally import small snippets containing interesting facts. In all cases, I comply with Creative Commons license requirements such as crediting the author.
