  Hunt The Wumpus was created by Gregory Yob in 1973 after seeing some of the hide and seek style games distributed by the People's Computer Company. Games such as Hurkle, Snark and Mugwump were all based on a 10x10 grid using Cartesian coordinates, but Yob thought that he could create a more interesting game without using a grid system and released it through the PCC.
